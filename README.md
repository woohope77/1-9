# 학급 기록장 (학생용 · 선생님용 분리판)

주소가 서로 다른 **두 개의 사이트**로 나뉘어 있습니다.
같은 Supabase 데이터베이스를 함께 쓰지만, 학생은 선생님용 주소를 알 수 없고
알더라도 비밀번호 없이는 아무 자료도 볼 수 없습니다.

```
student/    학생용 사이트   ← 학생에게 알려 주는 주소
teacher/    선생님용 사이트 ← 선생님만 아는 주소
supabase.sql               데이터베이스 설정 (한 번만 실행)
```

## 학생용 (`student/`)

- `index.html` `app.js` — 번호 + PIN을 넣어야 **본인 기록만** 보이고 새로 씁니다
- 활동 영역 7가지, 영역당 3개까지, 사진 업로드
- 선생님용으로 넘어가는 링크가 **아예 없습니다**

## 선생님용 (`teacher/`) — 세 화면

| 화면 | 하는 일 |
|---|---|
| `index.html` 활동 기록 | 학생들이 쓴 활동 기록 모아보기 · 엑셀 내려받기 · 자율/진로 특기사항 초안 |
| `dashboard.html` 학생 대시보드 | 학생 한 명의 **성적 · 상담 · 관찰한 장점 · 진로/독서** 를 기록하고, 이를 모두 근거로 **행동특성 및 종합의견** 초안을 만듭니다 |
| `students.html` 학생 명단 | 학생 추가 · 이름 수정 · 숨기기 · 삭제, 그리고 **학생 PIN 정하기·나눠 주기** |

세 화면 모두 **선생님 비밀번호**를 넣어야 열립니다. 한 번 넣으면 브라우저를 닫을 때까지 유지됩니다.

## 자료가 어떻게 보호되나

- 학생은 **번호 + PIN**이 맞아야 자기 기록을 열 수 있습니다. PIN은 **선생님이 정해서 나눠 줍니다**
  (선생님용 → 학생 명단 → *PIN 나눠 주기*). 번호만으로는 아무것도 보이지 않습니다.
- PIN 확인은 **서버 안에서만** 이루어집니다. 틀리면 서버가 기록을 아예 내주지 않고,
  PIN 값 자체는 학생용 사이트로 절대 나가지 않습니다.
- **성적 · 상담 기록**은 `student_notes` 표에 있고, 비밀번호를 통과한 요청에만 서버가 내줍니다.
  학생용 사이트의 코드에는 이 표를 부르는 경로 자체가 없습니다.
- 비밀번호는 `supabase.sql` 안에만 있고 웹사이트 파일 어디에도 없습니다.

> 성적과 상담 내용은 민감한 개인정보입니다. 학교에 따라 NEIS 외부에 학생 자료를
> 두는 것에 대한 지침이 있을 수 있으니 한 번 확인해 보시길 권합니다.
> 상담 기록에는 가정사처럼 특히 민감한 내용은 되도록 적지 않으시는 편이 안전합니다.

## 설치 순서

### 1 · 데이터베이스 설정

Supabase → **SQL Editor** → `supabase.sql` 전체 붙여넣기 → **Run**

- 맨 위 `'9011'` 자리에 선생님 비밀번호를 넣습니다
- 맨 아래 학생 명단을 우리 반에 맞게 고칩니다 (나중엔 화면에서 고칠 수 있습니다)
- 끝나면 Table Editor 에 `students` · `activities` · `student_notes` 세 표가 보입니다

### 2 · GitHub에 올리기

저장소에 `student` 폴더와 `teacher` 폴더를 **폴더째로** 끌어다 놓고 Commit 합니다.
기존에 루트에 있던 파일들은 그대로 두셔도 됩니다 (더 이상 쓰이지 않습니다).

### 3 · config.js 두 개 채우기

`student/config.js` 와 `teacher/config.js` 의 아래 두 줄에 **같은 값**을 넣습니다.

```js
SUPABASE_URL: "https://○○○○.supabase.co",
SUPABASE_KEY: "sb_publishable_○○○○",
```

### 4 · Vercel 프로젝트 두 개

**학생용 (기존 프로젝트 재사용)**
Vercel → 프로젝트 → **Settings** → **Build & Deployment** → **Root Directory** 를 `student` 로 바꾸고 저장 → **Redeploy**

**선생님용 (새 프로젝트)**
Vercel → **Add New… → Project** → 같은 저장소 **Import** →
**Root Directory** 를 `teacher` 로 지정 → **Deploy**
→ 나온 주소가 선생님용입니다. **학생에게 알려 주지 마세요.**

### 5 · (선택) AI 초안을 사이트에서 바로

기본값은 무료 방식(프롬프트를 만들어 ChatGPT·Claude에 붙여넣기)입니다.
사이트에서 바로 초안을 뽑으시려면 `teacher/config.js` 의 `MODE` 를 `"api"` 로 바꾸고,
**선생님용 Vercel 프로젝트**에 환경변수를 넣은 뒤 Redeploy 하세요.

| 이름 | 값 |
|---|---|
| `OPENAI_API_KEY` | `sk-...` |
| `TEACHER_PASSWORD` | `supabase.sql` 의 비밀번호와 같은 값 |

## 학기 중에 자주 쓰는 것들

- **학기 처음에** → 선생님용 → 학생 명단 → **PIN 없는 학생만 한꺼번에 만들기** →
  **명단 복사** → 각자에게 자기 PIN만 조용히 알려 주기
  (PIN을 잊은 학생이 있으면 그 줄의 **PIN 정하기**로 새로 정해 주면 됩니다)
- **학생 추가·전학** → 선생님용 → 학생 명단 (새로 넣은 학생은 PIN도 정해 주세요)
- **상담 직후** → 학생 대시보드 → 상담 기록에 바로 남기기
- **좋은 모습을 봤을 때** → 관찰한 장점에 한 줄. 학기 말 종합의견의 가장 좋은 재료입니다
- **학기 말** → 대시보드에서 학생을 고르고 **프롬프트 만들기** → ChatGPT나 Claude에 붙여넣기
  → 나온 초안을 **글자 수 확인** 칸에 넣어 한도를 넘지 않는지 보기
- **기록 내려받기** → 활동 기록 화면 → 엑셀(CSV)

## 글자 수 한도

| 항목 | 한도 |
|---|---|
| 자율활동 특기사항 | 500자 |
| 진로활동 특기사항 | 500자 |
| 행동특성 및 종합의견 | 300자 |

`teacher/config.js` 의 `length` 와 `SUMMARY_LENGTH` 로 바꿀 수 있습니다.
